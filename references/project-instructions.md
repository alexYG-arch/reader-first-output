# 项目日常使用

需要日常Chat默认采用时，将下列短稿合并到所用宿主支持的项目指令中。保留已有内容与优先级，不覆盖配置，不自动修改全局规则。此短稿与SKILL.md共同规则同步维护；深入改写或HTML时再调用本Skill。

> 回复、进度说明、报告和文档先回应当前问题，按读者知识解释对象、动作、关系和必要理由。简单问题保持简短，复杂内容才分层或配图，不强制套报告模板。
>
> 使用已有名词和普通语言，不为普通概念自造词、缩写或标签；没有合适名称时先直接描述。确需新命名时注明暂用并解释含义和用途。保留准确的专业词、项目名、命令、字段与原样引用，陌生含义按需解释。
>
> 不因好读丢失或改变本题事实、理由、条件、否定、范围、数量、状态、时间、版本、归属与不确定性。全文改写和完整HTML保留范围内全部独立信息，不自动摘要；图形和交互不能暗示不同结论，原文附件不能补救解释遗漏。发现冲突或疑似错误另行说明，不静默修正。
>
> 未说明的统计对象或分母保持未知，不从相邻信息猜归属；日期保留来源口径，换算要标时区。容易误解的项目术语在首次出现时解释实际对象，标题和图例也适用。
>
> 状态、失败和交接只说有依据的结果与可行下一步；历史记录不当当前验收或授权。只优化表达及所需呈现，不扩大业务功能、权限或执行范围。
>
> 不把假设或条件场景当成已发生事实，也不由当前状态倒推原因。给出建议也不暗中预设原因：未确认的情况保留为条件，或不补原因。

Codex中可使用项目AGENTS.md等受支持入口；其他工具按其实际机制配置。Skill显式/隐式选用与项目指令加载不是同一保证：改配置后按宿主方式重载，检查实际目录与会话。不要承诺一次调用覆盖所有项目、压缩后和新会话。

若希望 Codex 在所有项目和新聊天中默认采用，按 [全局指令短稿](codex-global-instructions.md) 设置用户级指令；项目内的具体要求和当前任务格式仍须保留。

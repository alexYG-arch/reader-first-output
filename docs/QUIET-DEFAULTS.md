# v0.4.3：直接应用默认表达规则

v0.4.2 的隔离首次安装测试证明了自动读取与配置保留，但有一次首轮问答在正确的两句话之前，多显示了一句“我会按 reader-first-output 的表达规则……”。最终答案格式通过，整轮可见输出格式未通过；原失败记录保留，不能把 final 正确等同于全部可见输出符合要求。

## 原因与修复

本次测试使用的 Codex 运行规则要求首次应用 Skill 时告知用户。v0.4.2 又要求每个新聊天为日常表达先读取并使用 Skill，因而普通短答可能触发这类告知。不能用 Skill 中的低优先级指令禁止宿主要求的通知，也不能在测试报告中删掉进度消息。

v0.4.3 调整职责：

- **普通 Chat、进度、报告和文档**：用户级或项目级 AGENTS 中的规则直接约束输出。新会话自动得到这些默认规则，用户无需点名 Skill，也不必为表达习惯启动额外流程。
- **设置默认规则、完整通俗改写、交互式 HTML、正式可读性审阅**：按任务使用 Skill，仍允许隐式选用，不要求每次显式调用。实际应用 Skill 时，保留宿主要求的必要告知。

Skill 本体仍提供共同表达方法、原意保护和按需操作方法；日常默认不是改成“只做内容转写”。变化的是规则进入日常对话的方式：从每个新聊天读取 Skill，改为宿主自动注入 AGENTS。普通 Chat 不读 Skill 正文是新版的预期，不能同时声称旧机制未变。

全局短稿保留了先回答问题、不造词、事实与条件保护，并补明单位、统计口径、冲突记录和未知机制。没有关闭隐式调用，没有隐藏真实工具活动，也没有改 Codex 运行规则或业务执行权限。

这与 OpenAI 对默认偏好和工作流的区分一致：用全局 AGENTS 约束沟通方式，用 Skill 提供具体任务的方法。[官方自定义说明](https://learn.chatgpt.com/docs/customization/overview)、[Skill 说明](https://learn.chatgpt.com/docs/build-skills)。

## 升级时要更新两处

更新 Skill 文件，并将新版 [全局短稿](../references/codex-global-instructions.md) 替换到实际生效的用户指令标记块中。只换 Skill 文件会留下旧的“每个新聊天读取 Skill”要求，不能完成这次修复。

保留原文件备份、标记块之外的内容、原权限和配置文件；已有非空 override 时仍合并到实际生效入口，不新建 override。相同新版块重复合并不产生重复。完整步骤见 [安装说明](INSTALL-CODEX.md)。

## 验证口径

普通问答应同时满足：实际注入新 AGENTS 规则；无需用户显式调用；未为默认表达额外调用 Skill；全部用户可见消息符合内容和格式。检查包含 commentary 与 final，不能仅审阅 answer.md。

专门的完整改写任务另行核对自然触发、Skill 正文与对应参考读取以及全部原意保留。它的必要使用告知不算普通问答的多余提示；这条区别在运行前定义，不能为某次失败临时放宽。

## 本次实际复测

使用 gpt-6.1-sol，在 macOS arm64 的隔离 Codex CLI 中验证三个配置情形：已有默认配置、自定义 CODEX_HOME、已有非空 override。使用临时用户目录，没有创建新系统账号；生成时只给自然问题，不提供预期答案或评测表。

| 阶段 | 实际运行 | 结果 |
| --- | --- | --- |
| 首次候选 | 8 个新会话、10 轮，其中 9 轮日常问答、1 轮完整改写 | 日常问答均无多余说明；原意 9/10 轮通过，整体仍记失败 |
| 通用原意保护修复后 | 3 个新会话、4 轮，原题和原断言不改 | 原意、格式和无多余说明均 4/4 通过 |
| 最终采用的证据 | 首轮未受影响 6 轮，加本次复测 4 轮 | 10/10 轮通过；这不是在最终文本下重跑了全部 10 轮 |

首轮发现的一处问题是：把“已排队只表示收到请求”解释成“结果文件还未生成完毕”。材料没有支持后一个确定的否定结论，因此保留失败，并在共同规则中补明“未确认”不等于“确定未发生或未完成”。随后在三种配置中重测同一首轮问题，另测一次自然追问，均通过。旧失败没有被改成通过。

累计运行 11 个新会话、14 轮。日常问答检查全部可见消息，没有额外 Skill 读取或使用说明；专门完整改写自然选用 Skill，并实际读取正文与改写参考，原始 7 项信息均保留。专门改写的这项证据来自补强前的候选，没有声称最终文本下重跑。原有 5 类 7 轮问题逐字保留。

三种情形中的原配置内容和权限均保留；旧块升级严格保持块外字节一致。两种首次追加情形各在标记块外增加一个换行作为分隔，没有更改原内容；最初回执将末尾换行计入标记块而表述过宽，已另存更正并保留旧回执。本次通用规则的三处替换均严格保持块外字节一致，重复合并不增加块，临时认证副本在两阶段结束后均已删除。

首批模型调用的墙钟时间约 80.85 秒，修复后的复测约 28.23 秒；其中有并行调用，不代表累计工时。时间戳和计数见下方摘要。没有重新执行历史完整 HTML 套件，也没有把旧版浏览器或 Desktop 证据算成本次复测。

本次候选修复的实际结果与范围见 [机器可读摘要](quiet-defaults-validation.json)。旧 v0.4.1、v0.4.2 的测试按其原版本与机制保留，见 [历史摘要](GLOBAL-VALIDATION.md)，不当作新版已重跑。

这里只验证所运行的环境和问题，不保证所有未来回答。AI 内容审阅不是真人理解测量；未实际执行的宿主、设备、浏览器或旧进程热更新不能称为通过。
